# Jogo Mario

## Descrição
Jogo inspirado no clássico Mario, feito em HTML, CSS e JavaScript. O personagem pula para desviar de um cano que se move em sua direção; ao colidir, o jogo termina.

## Objetivo
Pular no momento certo para evitar o cano e continuar jogando pelo maior tempo possível, sem ser atingido.

## Tecnologias
- HTML
- CSS
- JavaScript

## Instalação
Não é necessário instalar dependências. Basta clonar ou baixar o repositório:

https://github.com/luferc1/jogoMario.git

## Execução
Abra o arquivo `index.html` diretamente no navegador.
